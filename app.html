🔍 GA4 Property Audit — 40-Point Checklist

Connect to the GA4 Admin API and run a comprehensive property health check. Optional: use analytics.edit scope to auto-fix issues.

✓ Access token saved for this session
Step-by-step (60 seconds):
1. Open Google OAuth Playground in a new tab
2. On the left side, scroll down the list of APIs
3. Find and click Google Analytics Admin API v1beta to expand it
4. Check the box next to: https://www.googleapis.com/auth/analytics.readonly
   ↳ Also check Google Analytics Data API → https://www.googleapis.com/auth/analytics.readonly for live data flow checks
   ↳ Optional: also check analytics.edit to enable auto-fix buttons
5. Click the blue Authorize APIs button (bottom of left panel)
6. Sign in with the Google account that has access to your GA4 properties
7. On Step 2 → click Exchange authorization code for tokens
8. Copy the Access token (long string starting with ya29.) and paste below

🔒 Token expires ~1 hour. Stored in browser tab only. Read-only by default.

📦 GTM Container Audit

Inspect every tag, trigger, variable, and folder in your GTM container. Detect unused tags, naming issues, and missing configurations.

✓ GTM access token saved for this session
⚠ Important: GTM requires a DIFFERENT token than GA4. You cannot reuse your GA4 token here.

Step-by-step (60 seconds):
1. Open Google OAuth Playground in a new tab
2. On the left side, scroll down the list of APIs
3. Find and click Tag Manager API v2 to expand it
4. Check the box next to: https://www.googleapis.com/auth/tagmanager.readonly
5. Click the blue Authorize APIs button (bottom of left panel)
6. Sign in with the Google account that has access to your GTM containers
7. On Step 2 → click Exchange authorization code for tokens
8. Copy the Access token (long string starting with ya29.) and paste below

🔒 Read-only. Expires in ~1 hour. Your container is never modified. If you get "expired" — generate a fresh token.
