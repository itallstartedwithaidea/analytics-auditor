✓ Access token saved for this session
How to get your access token (takes 60 seconds):
1. Open Google OAuth Playground
2. In Step 1 → find Google Analytics Admin API v1beta → select https://www.googleapis.com/auth/analytics.readonly
3. Click Authorize APIs and sign in with your Google account
4. In Step 2 → click Exchange authorization code for tokens
5. Copy the Access token and paste it below

🔒 Token expires in ~1 hour. Only stored in your browser tab — never sent to our servers. Read-only access — nothing is modified.
