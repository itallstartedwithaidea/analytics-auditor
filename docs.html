Analytics Auditor Docs

The Marketing Analytics Auditor is a free, open-source tool that scans websites for GA4, GTM, and marketing pixel configurations, identifies issues, and generates the exact remediation code to fix them.

Current Status: Phase 1 (Page Scanner + Tag Detection + Remediation) is live. GA4 Admin API audit (Phase 2) and AI Vision scanning (Phase 5) are in development. Contribute on GitHub →

Quick Start

The page scanner requires zero setup — no API keys, no login, no installation. Three ways to use it:

Option 1: Scan a URL

Enter any URL in the scanner. The tool fetches the page via a CORS proxy and analyzes the HTML for marketing tags. Best for quick checks on public pages.

Option 2: Paste HTML source

Right-click any page → View Page Source (Ctrl+U), copy the full HTML, and paste it into the "Paste HTML" tab. This captures JavaScript-injected tags that may not appear in a simple fetch. Recommended for accuracy.

Option 3: Demo mode

Click "Demo Scan" to run a simulated audit against a fake ecommerce site. Shows the full experience — tag detection, issue identification, scoring, and remediation code — without needing a real URL.

Security & Privacy

🔒 Your data never leaves your browser. All page analysis runs client-side in JavaScript. No HTML content, URLs, or scan results are sent to any server we control. The CORS proxy only forwards the raw page — it does not log or store content.

Security principles

  • Zero server-side storage. No database, no user accounts, no cookies from us.
  • Keys in sessionStorage only. Cleared when the browser tab closes. Never written to localStorage or sent to any backend.
  • Open source. Every line of code is auditable on GitHub. No obfuscation, no telemetry, no analytics.
  • No third-party scripts. No Google Analytics, no Meta Pixel, no tracking on the tool itself. Google Fonts is the only external resource.
  • API calls go direct. When you connect to GA4 Admin API or Gemini, calls go directly from your browser to Google's APIs. We are never a middleman.

Scan a URL

Enter any publicly accessible URL. The scanner fetches the page HTML via api.allorigins.win (a public CORS proxy) and analyzes it for marketing tags.

Limitations of URL scanning: The proxy fetches the initial HTML response only. Tags injected by JavaScript after page load (common with SPAs) may not be detected. For these sites, use the "Paste HTML" method instead.

The scanner checks for tags using four methods:

  • DOM script tags — Pattern matching on <script> src attributes
  • JavaScript globals — Detection of window objects like fbq, ttq, gtag
  • Network patterns — URLs referencing known analytics endpoints
  • Cookie signatures — Known cookie names like _ga, _fbp, _ttp

Paste HTML

For the most accurate results:

  1. Open the target page in your browser
  2. Right-click → View Page Source (or Ctrl+U / Cmd+U)
  3. Select all (Ctrl+A) and copy (Ctrl+C)
  4. Switch to the "Paste HTML" tab in the auditor
  5. Paste and click "Analyze HTML"

This method captures the complete server-rendered HTML including any tags in the <head> and <body>. For JavaScript-rendered tags, you can also use browser DevTools (Elements tab → copy <html> outerHTML) to capture the fully rendered DOM.

Demo Mode

Demo mode simulates scanning https://acme-ecommerce.com, a fictional ecommerce site with a typical tag setup: GA4 via GTM, Meta Pixel with partial Advanced Matching, Google Ads conversion tracking, TikTok base pixel without events, and missing LinkedIn Insight tag.

The demo generates realistic issues and remediation code so you can explore the full audit experience before scanning a real site.

GA4 Audit: Setup & OAuth

PHASE 2 Connect your Google account to run a full 40-point GA4 property audit via the Admin API.

Required scopes

https://www.googleapis.com/auth/analytics.readonly

The auditor requests read-only access. It cannot modify your GA4 property settings, create events, or change any configuration. The OAuth token is stored in sessionStorage only — it is never persisted and is cleared when you close the tab.

Setup steps

  1. Click "Connect GA4" in the auditor
  2. Sign in with the Google account that has access to your GA4 property
  3. Grant read-only analytics access
  4. Select the property to audit from the dropdown
  5. Click "Run Audit" — results appear in ~5 seconds

GA4: Grading Scale

Same A–F grading as the page scanner. Start at 100, subtract penalties per severity. GA4 audit and page scan scores are presented separately so you can see property configuration health vs. on-page implementation health independently.

Pixel Validation

For each detected pixel, the scanner validates:

  • Base code: Is the pixel script loading correctly?
  • Standard events: Are platform-recommended events configured? (PageView, ViewContent, AddToCart, Purchase, etc.)
  • Advanced Matching: Are hashed user identifiers being passed? (email, phone, name)
  • Consent integration: Does the pixel respect consent state?

CAPI Checks

PHASE 3 For platforms supporting server-side events (Meta, Google, TikTok), the auditor checks:

  • Whether CAPI endpoints are active
  • Event match quality scoring (Meta Marketing API)
  • Deduplication parameters (event_id present)
  • Required user data fields (em, ph, client_ip_address, client_user_agent)
  • Event coverage comparison: client-side only vs. server-side redundancy

Remediation Code Generation

For every issue found, the auditor generates platform-specific, copy-paste-ready code. This is the core differentiator — no other tool does this.

Types of generated code

Issue TypeGenerated Fix
Missing dataLayer eventsdataLayer.push() with correct event name, parameters, and placement instructions
Missing GTM tagsGTM container JSON fragment importable via GTM UI
Missing pixel eventsPlatform-specific event code (fbq, ttq, etc.) with required parameters
Missing pixels entirelyFull base code installation snippet
Missing CAPIServer endpoint boilerplate in Node.js (Python and PHP planned)
Missing consentGoogle Consent Mode v2 default + update template
Missing Enhanced Conversionsgtag('set', 'user_data', {...}) template

Using remediation code

  1. Click "Show remediation code" on any issue
  2. Click "Copy" to copy to clipboard
  3. Replace placeholder values ({{ORDER_ID}}, {{PIXEL_ID}}, etc.) with your actual dynamic values
  4. Deploy via GTM custom HTML tag, or paste directly into your page template
  5. Test using GTM Preview Mode or browser DevTools console

GTM Container Import

PHASE 4 For issues that can be fixed via GTM, the auditor generates importable container JSON files. To import:

  1. Export the GTM container JSON from the auditor
  2. Open your GTM container → Admin → Import Container
  3. Choose "Merge" → "Rename conflicting tags"
  4. Review the imported tags, triggers, and variables
  5. Test in Preview Mode before publishing

Developer Handoff

Click "Download Remediation Code" to get a complete developer handoff document containing:

  • Priority-ordered fix list (Critical → Low)
  • Exact code snippets for each fix
  • File/page placement instructions
  • Testing verification steps
  • Estimated implementation complexity

AI Page Vision

PHASE 5 Uses Gemini Vision or Claude Vision to analyze page screenshots and suggest tracking events based on visible interactive elements.

The AI identifies forms, CTAs, navigation elements, ecommerce components, engagement widgets, and conversion elements. Each suggestion includes a recommended GA4 event name, parameters, and priority level. Suggestions are mapped against existing tracking from the page scan to identify gaps.

Requires: Gemini API key or Claude API key (stored in sessionStorage only).

Multi-Site Portfolio

PHASE 6 Manage multiple sites with a standardized tracking schema. Define required events, naming conventions, and pixel requirements at the portfolio level. Run audits across all sites and compare coverage side-by-side.

Designed for agencies and portfolio companies managing 10–100+ properties.
