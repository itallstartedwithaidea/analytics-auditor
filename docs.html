Analytics Auditor Docs

The Marketing Analytics Auditor is a free, open-source tool that scans websites for GA4, GTM, and marketing pixel configurations, runs a 40-point GA4 property audit via the Admin API, uses AI to discover untracked page elements, and generates the exact remediation code to fix every issue found.

All features are live: Page Scanner, GA4 Property Audit (40-point checklist), AI Page Vision (Gemini), and Remediation Code Generation are all available now. Launch the Auditor →

Quick Start

Page Scanner (zero setup)

No API keys, no login, no installation. Enter any URL or paste HTML source code and get an instant tag inventory, health score, and remediation code.

  1. Go to the Auditor app
  2. Enter a URL or switch to "Paste HTML"
  3. Review your tag inventory, score, and issues
  4. Click "Show remediation code" on any issue for copy-paste fix code

GA4 Property Audit (needs Google OAuth token)

  1. Open the GA4 Audit tab in the Auditor
  2. Follow the OAuth Playground instructions to get a read-only access token (60 seconds)
  3. Paste the token and select your property
  4. Click "Run 40-Point Audit" — results in ~5 seconds

AI Vision (needs free Gemini API key)

  1. Open the AI Vision tab
  2. Get a free API key from Google AI Studio
  3. Enter a URL and click "Analyze with AI"
  4. Review the suggested tracking events mapped to GA4 event names

Security & Privacy

🔒 Your data never leaves your browser. All page analysis runs client-side in JavaScript. No HTML content, URLs, API keys, or scan results are sent to any server we control. API calls go directly from your browser to Google's APIs. We are never a middleman.

How credentials are handled

Security principles

  • Zero server-side storage. No database, no user accounts, no cookies from us.
  • Keys in sessionStorage only. Cleared when the browser tab closes. Never written to localStorage or sent to any backend.
  • Read-only API access. GA4 audit uses analytics.readonly scope — it cannot modify your property.
  • Direct API calls. When you connect to GA4 Admin API or Gemini, calls go directly from your browser to Google. We are never in the middle.
  • Open source. Every line of code is auditable on GitHub. No obfuscation, no telemetry, no analytics.
  • No third-party scripts. No Google Analytics, no Meta Pixel, no tracking on the tool itself. Google Fonts is the only external resource.

Scan a URL

Enter any publicly accessible URL. The scanner fetches the page HTML via CORS proxy and analyzes it for marketing tags. The tool tries multiple proxy services automatically — if one fails, it falls back to the next.

Limitations of URL scanning: CORS proxies fetch the initial HTML response only. Tags injected by JavaScript after page load (common with SPAs and React/Next.js sites) may not be detected. For these sites, use "Paste HTML" instead — it captures the full rendered DOM.

The scanner checks for tags using four methods:

  • DOM script tags — Pattern matching on <script> src attributes and inline code
  • JavaScript globals — Detection of window objects like fbq, ttq, gtag, dataLayer
  • Network patterns — URLs referencing known analytics endpoints
  • Cookie signatures — Known cookie names like _ga, _fbp, _ttp

Paste HTML

For the most accurate results, paste the page source directly:

  1. Open the target page in your browser
  2. Right-click → View Page Source (or Ctrl+U / Cmd+U)
  3. Select all (Ctrl+A) and copy (Ctrl+C)
  4. Switch to the "Paste HTML" tab in the auditor
  5. Paste and click "Analyze HTML"

For JavaScript-rendered tags (SPAs), use browser DevTools: Elements tab → right-click the <html> element → Copy → Copy outerHTML. This captures the fully rendered DOM including dynamically injected scripts.

GA4 Audit: Setup (OAuth Playground)

LIVE Connect your Google account to run a full 40-point GA4 property audit via the Admin API. The entire process takes about 60 seconds.

Step-by-step

  1. Open the GA4 Audit tab in the Auditor app
  2. Click the link to Google OAuth Playground
  3. In Step 1, scroll to Google Analytics Admin API v1beta and select:
    https://www.googleapis.com/auth/analytics.readonly
  4. Click Authorize APIs — sign in with the Google account that has access to your GA4 property
  5. In Step 2, click Exchange authorization code for tokens
  6. Copy the Access token value (starts with ya29.)
  7. Paste it into the Auditor's token field and click Save & Load Properties
  8. Select your property from the dropdown and click Run 40-Point Audit
Token expires in ~1 hour. If you get a 401 error, return to OAuth Playground and generate a new token. The token grants read-only access — it cannot modify your GA4 property settings.

Required scope

https://www.googleapis.com/auth/analytics.readonly

This scope provides read-only access to property settings, data streams, enhanced measurement configuration, key events, product links, custom dimensions, audiences, and attribution settings. It cannot create, modify, or delete anything.

GA4: 40-Point Checklist

LIVE The audit queries the GA4 Admin API and checks 7 categories:

CategoryChecksKey Items
Property Configuration7+Timezone, currency, industry category, data retention (14mo vs 2mo), attribution model, reporting attribution
Data Streams2+Web stream exists, measurement ID valid and active
Enhanced Measurement8Master toggle, page views, scrolls, outbound clicks, site search, video engagement, file downloads, form interactions
Key Events3+At least 1 key event defined, industry-appropriate events (purchase or generate_lead), counting method
Product Links1+Google Ads linked
Custom Definitions2+Custom dimensions defined, naming conventions (snake_case, no spaces)
Audiences1+Audiences beyond defaults (All Users + Purchasers)

Each check returns ✓ Pass, ⚠ Warning, ✗ Fail, or — N/A. The overall score starts at 100 and deducts 10 for failures and 3 for warnings.

GA4 Audit Grading

The GA4 audit uses the same A–F grading scale as the page scanner. Common issues that drop scores:

  • Data retention set to 2 months (default) — should be 14 months
  • No key events defined — GA4 is collecting data but not measuring conversions
  • Enhanced measurement toggles off — missing scroll, video, file download tracking
  • Google Ads not linked — conversion data not flowing to ad campaigns
  • No custom dimensions — missing user segmentation capability
  • Only default audiences — no retargeting audiences built

AI Vision: Gemini API Key Setup

LIVE The AI Vision feature uses Google's Gemini 2.0 Flash model to analyze webpage HTML and identify every trackable interactive element.

Get your free Gemini API key

  1. Go to Google AI Studio
  2. Sign in with any Google account
  3. Click Create API key
  4. Copy the key and paste it into the Auditor's AI Vision tab
🔒 Your API key never touches our servers. The call goes directly from your browser to generativelanguage.googleapis.com. We never see your key. It's stored in sessionStorage only — gone when you close the tab.

The free tier of Gemini API provides generous usage limits for individual audits. No billing setup is required.

AI Vision: How It Works

When you run an AI Vision scan:

  1. The tool fetches the page HTML via CORS proxy (same as Page Scanner)
  2. The HTML (truncated to fit context) is sent to Gemini 2.0 Flash with a specialized analytics prompt
  3. The AI identifies every interactive element on the page that should be tracked
  4. Results are returned as structured data with GA4 event recommendations

The AI looks for 6 categories of trackable elements:

  • Forms — Contact forms, signup forms, newsletter opt-ins, search boxes
  • CTAs — Buttons and links that are calls-to-action (Buy Now, Get Started, etc.)
  • Navigation — Menu items, category links, filter controls
  • Ecommerce — Product cards, add-to-cart buttons, wishlist, cart icon
  • Engagement — Video players, image carousels, tabs, accordions, chat widgets
  • Conversion — Phone numbers, email links, booking/scheduling widgets

AI Vision: Output

For each element the AI finds, you get:

FieldDescription
Event nameRecommended GA4 event name in snake_case (e.g., generate_lead, view_item)
ElementDescription of the interactive element and its location
ParametersKey parameters to capture (e.g., form_name, button_text, video_title)
PriorityCritical, High, Medium, or Low
TrackedYes, Partial, or No — based on what the AI sees in the existing HTML

If you've already run a Page Scan, the AI Vision results complement it by finding elements that the DOM-based scanner can't detect (interactive behaviors, visual CTAs, etc.).

Using remediation code

  1. Click "Show remediation code" on any issue
  2. Click "Copy" to copy to clipboard
  3. Replace {{PLACEHOLDER}} values with your actual dynamic values (e.g., {{ORDER_ID}}, {{PIXEL_ID}})
  4. Deploy via GTM custom HTML tag, or paste directly into your page template
  5. Test using GTM Preview Mode, Meta Pixel Helper, or browser DevTools console

Session Storage

The Auditor uses sessionStorage to keep your credentials and scan results available for the duration of your browser session.

What's stored

KeyValueLifetime
ga4_tokenGoogle OAuth access tokenUntil tab closes or token expires (~1 hour)
gemini_keyGemini API keyUntil tab closes

Scan results (tags, scores, issues) are held in JavaScript memory only — not written to sessionStorage. They persist as long as you don't refresh the page.

Clearing your data

Use the Settings tab to view, clear individual keys, or nuke everything with "Clear All Keys & Data." Closing the browser tab also clears everything automatically.

API Reference

The scan engine is a set of JavaScript functions embedded in app.html. Key functions available in the global scope:

// Run a scan on HTML string
var result = scanHTML(htmlString, 'https://example.com');

// Result structure:
{
  url: string,
  scannedAt: string,        // ISO 8601
  tags: { [key]: TagResult },
  consent: ConsentResult,
  issues: Issue[],
  score: number,             // 0-100
  grade: string,             // A-F
  gradeLabel: string,
  tagCount: number,
  issueCount: number
}

// Each issue:
{
  sev: 'critical' | 'high' | 'medium' | 'low',
  title: string,
  desc: string,
  fix: string  // Copy-paste remediation code
}

For integration into other tools, the TAG_DEFS object contains all platform detection signatures and can be extended with new platforms. See CONTRIBUTING.md for instructions.
